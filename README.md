# Maurya Shivani – Portfolio

Personal portfolio website built with React + Vite, based on Maurya Shivani's resume.

## Run locally

```bash
npm install
npm run dev      # start dev server
npm run build    # production build in dist/
npm run preview  # preview the production build
```

All content (profile, skills, projects, experience, education) lives in `src/data.js` — edit that file to update the site.
